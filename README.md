# 艾爾琳練習簿

瑪奇生活技能修練模擬器，繁體中文介面。依照噴嚏精靈的[生活技能修練試算表](https://docs.google.com/spreadsheets/d/1Ax4M2ycAv-XMDUo-DldQVt3cGiYRaz5cCTCONSoH46c/edit?gid=785953580#gid=785953580)，收錄 9 技能、529 項修練。

## 本機使用

需要 Node.js 20 以上，無第三方執行依賴。

```sh
npm run dev
```

開啟終端機顯示的網址。選擇技能、目前 Rank 與目標 Rank，調整倍率。各階級可勾選修練項目；原表提供替代配方時，可切換配方。材料清單即時更新。若已有進度，同時填入已取得修練值與各項已計數次數。

```sh
npm test
npm run check
```

測試涵蓋倍率封頂、項目上限、非整數倍率、Rank 區間、既有進度、材料、替代配方與全部技能數值一致性。

## GitHub Pages

公開網站檔案全部位於 `dist/`，採相對網址，支援專案子路徑。建立 GitHub 儲存庫並推送 `main` 後，在 Settings → Pages → Source 選擇 GitHub Actions。隨附工作流程會先測試，再部署 `dist/`。無需後端或付費網域。

若 GitHub CLI 登入失效，先執行 `gh auth login -h github.com`。也能將 `dist/` 交給其他靜態網站服務代管。

## 計算規則

```text
新增修練值 = 基礎值 × 修練值倍率 × min(剩餘計數上限, 達成次數 × 次數倍率)
```

次數倍率上限 8，達成次數取整數。既有修練值不隨新倍率重算，各項已計數從上限扣除。每階以 100 為目標，計算區間排除目標 Rank；Rank 1 → Rank 1 沒有追加需求。

依原表建議順序計算，再納入額外勾選項目。若上限不足 100，顯示差額；後續階級只作條件式估算。沒有比較材料價格或求最低耗材。

材料採直接配方用量乘以各項達成次數。成功、失敗、大成功不是每次嘗試都會發生。同次行動觸發多項修練尚未合併，中間產物與跨階再利用尚未展開或抵扣，因此結果不是保證的操作或採購數量。

## 倍率版本

倍率於 **2026-09-12** 依 Mabinogi World／北美版查核，與原表的技能資料日期分開維護。所有效果預設關閉，活動倍率預設 1。修練水依同一技能擇一；次數倍率封頂 8，修練值獨立乘算。

細工、回音、徽章及農場工房按技能提供選項。普通修練 EXP 詞條每級增加 10%，一般上限 10 級；其他實際裝備效果可自訂。Catsidhe 需配對建立時選定的才能，魔力賦予使用戰鬥才能型，其餘收錄技能使用生活才能型。

切換技能會重設技能限定效果，保留綜合修練水、Blue Prism 與手動活動倍率。來源、衝突判讀及尚未核實的條件見 [倍率查核紀錄](docs/MULTIPLIERS.md)。台服道具與活動仍需依遊戲內顯示確認。

## 資料範圍

收錄打鐵、芬恩寶珠閃耀、衣物製作、芬恩的手工藝、魔力賦予、魔法製造、稀原工學、手工藝、文具工藝。

原表更新於 **2025-02-04**，快照擷取於 **2026-09-12**。共 129 筆一般 Rank、529 項修練。部分技能沒有 Rank 1 訓練資料；6 組升段／大師附錄保留在 JSON，未納入模擬。每項均附工作表與來源列，便於核對。

部分魔法製造材料公式依賴其他修練列，標為 `partial`；配方未提供者標為 `not-provided`。材料簡稱沿用原表，不將缺漏當零耗材。原表總材料公式的 `/2` 用於排除重複小計，網站沒有把材料減半。

[台服 NEW RISE 公告](https://mabinogi-event.beanfun.com/EventAD/EventAD?EventADID=15874)更新 AP 訓練規則，原表「總次數 10 以下無法 AP 修練」已不適用。此版不估算 AP、成功率、升段或大師修練，也不套用已移除的角色等級修練加成。效果是否適用該技能，請以遊戲內顯示為準。
